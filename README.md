# LLM-ассистент для исследователя, помогающего в проведении исследовательских задач в области ML.

 Ассистент на базе больших языковых моделей (LLM), предназначенный для автоматизации сбора, семантической фильтрации и глубокого анализа исследовательских данных в области Machine Learning (ML).

---

## Архитектура системы

В системе реализован надежный конвейер **Retrieval-Augmented Generation (RAG)**, оптимизированный для локального запуска с аппаратным ускорением (PyTorch / GPU):

1. **Ingestion Pipeline (Подготовка данных):** 
   - **Веб-парсинг:** Автоматическое извлечение и очистка чистого текста из HTML-страниц с помощью библиотеки `trafilatura` (удаление рекламы и мусора).
   - **Загрузка файлов:** Прямая интеграция локальных документов (`.pdf` через PyPDF2, `.txt`, `.md`, `.csv`).
   - **Чанкинг:** Семантическая нарезка текста с перекрытием токенов (overlap) для сохранения целостности контекста.
2. **Retrieval Pipeline (Поиск):** 
   - **Dense Retrieval:** Векторизация с помощью `sentence-transformers` (`paraphrase-multilingual-MiniLM-L12-v2`) и расчет косинусного сходства на GPU.
3. **Генерация и рассуждения:** 
   - Работа с локальными open-source моделями через **Ollama**. Реализована стратегия **Chain of Thought (CoT)** (План $\rightarrow$ Структурированная генерация) для исключения галлюцинаций и достижения максимальной технической глубины.

---

## Технологический стек

* **Язык программирования:** Python 3.11
* **Интерфейс:** Streamlit (Интерактивное веб-приложение)
* **LLM-сервер:** Ollama (модели Qwen 3.5: 27B и 4B)
* **Эмбеддинги и поиск:** PyTorch, Sentence-Transformers
* **Парсинг:** Trafilatura, PyPDF2
* **Оценка качества:** Автоматизированный фреймворк LLM-as-a-Judge (попарное сравнение Pairwise Comparison)
